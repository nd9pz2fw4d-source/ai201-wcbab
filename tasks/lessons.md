# Lessons

## Sources: "recent" means check the date
- Pattern: asked to use Deloitte's "recent" whitepaper, I used the first Deloitte report search returned (2020) and only flagged its age at the end. The user had to send the link to the August 2026 paper.
- Rule: when a request says "recent", "latest" or "new", confirm the publication date before building on a source. If the best hit is more than a year old, search again with the current year and the publisher's newer paths ("perspectives", "insights"), and if nothing newer turns up, ask before building rather than after.

## Voices: let the user hear and choose early, and keep accents neutral unless asked
- Audition a few voices on one real line from the script before generating a whole voiceover; never spend credits on the full script with a voice the user hasn't heard.
- "Someone from Alberta would find welcoming" did not mean an Alberta or Canadian accent: the user wanted neutral North American voices. Read a regional brief as tone and references, not accent, unless the user says accent.
- Offer the user the option to pick voices themselves from the ElevenLabs library; they may already know what they want.
