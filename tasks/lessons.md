# Lessons

## Sources: "recent" means check the date
- Pattern: asked to use Deloitte's "recent" whitepaper, I used the first Deloitte report search returned (2020) and only flagged its age at the end. The user had to send the link to the August 2026 paper.
- Rule: when a request says "recent", "latest" or "new", confirm the publication date before building on a source. If the best hit is more than a year old, search again with the current year and the publisher's newer paths ("perspectives", "insights"), and if nothing newer turns up, ask before building rather than after.
